-- Static libs
----------------------------------------------
 In the C/C++ view
  Import->File system 
  	from directory External_libs/xmlrpc-c/build
	into xmlrpc-c
	select all in /include
     Include also Optional_Libs/MastRpc, Optional_Libs/MastXmlRpc and Mast_Headers	
  Go to mast-dev_tml->Properties->C/C++ Buils -> Settings
   GCC C++ Compiler -> Includes
      From "workspace", add xmlrpc-c/include, MastRpc, MastXmlRpc and Mast_Headers	
   GCC C Compiler -> Includes
       The same (should not be needed, but to be on the safe side)
       
  G++ Linker --> Libraries
      Libraries: 
        add all the library names (for libSOMETHING.a, it is SOMETHING)
	File Linkers_Include has a list
      Library search path:
	      From "workspace", add xmlrpc-c/lib, where your .a files should be

In C/C++ General -> Paths and Symbols
  Library Paths: set xmlrpc-c/lib es EXPORT

Bit ordering: when generating a vector from an INTERGER
 bits are taken in a Big Endian way starting from to MSB the LSB (left to right)
 
When set into an ARRAY_I, values are shifted starting from Element 0
